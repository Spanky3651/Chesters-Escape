          Save for the game keeps it in this browser. In host tools, choose "Start a new game on the designer board". The board file is what goes into the game repo for the live game.

          Rewrite a theme's cards and the names on its event spaces. Each card shows how it will look in the game. What a card does stays the same, so the game stays fair. When you're done, download the card pack and send the file to MSploit in Discord.
